# Trade Square Hub

Build a modern, premium, animated 4-page website for "Trade Square Premises Cooperative Society Ltd.", a commercial office building in Mumbai. This must use ONLY real, verified information and real uploaded photos — do not invent, assume, or fabricate any data, pricing, payment options, amenities, reviews, or stock imagery anywhere on the site. If a piece of information isn't provided below, leave a clearly marked "Content coming soon" placeholder instead of making something up.

Currency rule: this is an Indian business. Use the ₹ (INR) symbol everywhere money is shown. Never use $ or USD anywhere on the site.

=== BRAND & DESIGN SYSTEM ===
Color theme: a unique, medium-toned blue — not navy-dark, not pastel-light.
- Primary Blue: #1B5FA8 (buttons, links, nav highlights, section accents)
- Deep Blue (headers/footer/text on light bg): #0B2E52
- Secondary/Sky tint (section backgrounds): #EAF3FC
- Accent Gold: #C9A227 (used sparingly — badges, dividers, icons — matching the society's existing navy-and-gold event branding)
- Neutral White: #FFFFFF and Neutral Slate: #33475B for body text

Typography: a clean modern sans-serif ("Inter" or "Poppins") for body text, a bolder display font for headings. Generous whitespace, rounded corners (12–16px), soft shadows.

Logo: I do not have a logo yet. Design a clean, modern wordmark/emblem logo for "Trade Square" using the blue + gold theme — a stylized building/skyline icon or a geometric "TS" monogram — and use it in the header and footer.

Animation & interaction requirements:
- Animated hero section (fade/slide-in on the building image + headline)
- Scroll-reveal animations for sections (fade-up, staggered cards)
- Smooth hover states on buttons/cards (scale + shadow lift)
- Animated counters for key stats (floors, units, year established)
- Sticky/transparent-to-solid header on scroll
- Lightbox/gallery viewer for event photos with smooth transitions
- Fully responsive (mobile-first), fast-loading, accessible (proper contrast, alt text, keyboard nav)
